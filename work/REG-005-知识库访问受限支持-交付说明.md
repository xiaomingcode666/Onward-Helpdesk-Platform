# REG-005 知识库访问受限支持（Access 最小版）

日期：2026-09-18

## 本次范围

REG-005 原文要求检查 Expert、Access、Knowledge、Monitoring、OLA 五类支持条件。本项目是知识库问答系统，本次按用户确认的最小业务流程，只实现知识库 Access：

- 客户问题对应到知识库。
- 工单记录 AI Agent 使用的首要知识库。
- 工单分配到支持团队或工程师后，检查该团队或工程师是否有知识库访问授权。
- 缺少授权时，工单记录 `restricted_support`、原因码、原因说明和检查时间。
- 改派、知识库变更、授权变更后重新检查。
- 知识库页面和工单详情提供支持状态与原因。

Expert、Knowledge、Monitoring、OLA 尚未实现，因此 REG-005 不能整体标记为完成。

## 数据与接口

- 新增 `t_knowledge_access_grant`，记录知识库对团队或用户的访问授权。
- 工单新增 `knowledge_base_id`，保存建单时使用的首要知识库。
- 工单新增：
  - `support_status`
  - `support_reason_code`
  - `support_reason`
  - `support_checked_at`
- 新增接口：
  - `GET /api/enterprise/v1/knowledge-bases/:knowledgeBaseId/access-grants`
  - `PUT /api/enterprise/v1/knowledge-bases/:knowledgeBaseId/access-grants`
- 迁移：`150 add knowledge access grants and ticket support readiness`、`151 migrate module access support to knowledge bases`

## 触发时机

- 创建工单并指定负责人。
- 自动派单、人工改派、会话派单和主管兜底。
- 工单修改后更换知识库。
- 知识库访问授权增加、删除或更换。

状态变化会追加 `support_readiness` 工单进度，不覆盖历史检查结果。

## 页面

- 企业知识库页面提供“维护访问授权”入口，可选择支持团队。
- 工单详情显示“支持状态”、受限原因和检查时间。
