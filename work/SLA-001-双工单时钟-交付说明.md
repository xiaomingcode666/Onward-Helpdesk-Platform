# SLA-001 双工单时钟交付说明

日期：2026-09-17。状态：开发完成，待用户验收。

## 已实现

1. 每个工单同时计算：
   - End-to-end Elapsed Clock
   - DayPop Accountable Clock
   - External Supplier Wait
2. 供应商邀请自动暂停责任时钟。
3. 供应商解决、超时、授权过期或工单关闭时恢复责任时钟。
4. 多个并发供应商等待只形成一次工单级暂停，结束最后一个等待后才恢复。
5. 工单中心和“处理工作台”展示总处理时间、供应商等待和责任处理时间。
6. SLA 风险、工作台统计和报表使用有效责任期限：

```text
暂停中：使用暂停开始时固化的剩余责任时间
恢复后：原 SLA 截止时间顺延实际暂停时长
```
