# 文件病毒扫描：免费、开源与商业版调研及选型建议

调研日期：2026-09-15。范围：Helpdesk 上传附件（PDF、图片、Office、压缩包）的病毒与恶意文件扫描。

## 结论

建议当前项目采用 **ClamAV 私有化部署 + FreshClam 病毒库更新 + 现有上传安全校验**。后续按实际风险增加 YARA-X、oletools；当客户需要多引擎、SLA、威胁情报或合规报告时，再采购商业多引擎平台。

VirusTotal Public API 不适合作为生产方案：官方明确禁止公共 API 用于商业产品或服务。

## 方案对比

| 类型 | 方案 | 许可/费用 | 功能 | 主要差距 |
|---|---|---|---|---|
| 开源杀毒引擎 | ClamAV | 免费；GPLv2 | 病毒、木马、恶意内容、常见归档解析；clamd 常驻服务 | 漏报/误报、规则和运维需自行负责；分发时需履行 GPL；可选 UnRAR 组件有单独许可 |
| 开源规则引擎 | YARA-X | 免费；BSD-3-Clause | 自定义文本、二进制和逻辑规则；可做行业特征检测 | 不自带完整病毒库；规则版权需单独核查；需要自行维护规则和资源限制 |
| Office 专项工具 | oletools | 免费；主体 BSD，部分 MIT | VBA/XLM 宏、DDE、OLE、RTF 和嵌入对象分析 | 属于文档风险分析，不等同完整杀毒；第三方依赖需另查许可 |
| 免费云 API | VirusTotal Public API | 免费额度；官方禁止商业产品使用 | 云端多引擎结果和文件分析 | 商业禁用；文件需发送到第三方；有请求速率和每日额度限制 |
| 商业多引擎 | OPSWAT MetaDefender 等 | 订阅、按量或私有化授权 | 多引擎扫描、沙箱/威胁情报、API、报表、SLA（以合同为准） | 成本高；需确认数据驻留、文件保留、并发、配额和退出条款 |
| 终端防护 | Defender、Sophos、Bitdefender 等 | 商业订阅或企业授权 | 主机和终端整体防护 | 通常不是应用上传同步接口，需额外适配 |

## 关键差距

| 维度 | ClamAV/YARA-X/oletools | 商业多引擎平台 |
|---|---|---|
| 检测覆盖 | 单引擎或规则专项，能力取决于病毒库和规则 | 多引擎、云情报和部分行为分析，通常覆盖更广 |
| 数据隐私 | 可完全留在自有网络 | 云方案会传输文件或摘要；私有化可降低外传风险 |
| 误报处理 | 自行白名单、回滚和规则调优 | 通常有厂商支持和更丰富上下文 |
| 扩展与可观测性 | 自行建设队列、监控、告警和容量 | 常带集群、报表、配额与 SLA |
| 成本 | 软件零许可费，但有服务器、维护和规则成本 | 持续订阅/按量/私有化费用 |
| 商业责任 | 主要由项目方承担 | 合同可约定支持、响应和服务边界，但不代表厂商保证绝对不漏报 |

## 当前项目适配情况

当前代码已有上传前文件大小、MIME、文件头、危险扩展名、EICAR、ZIP/Office 容器检查，并通过 TCP INSTREAM 调用 ClamAV。示例配置中 ClamAV 默认关闭，生产部署、FreshClam、病毒库过期告警和真实引擎联调尚未完成。

接入前必须处理：

1. “发现感染”和“扫描服务不可用”必须分开；感染结果无论 fail-closed 配置如何都应拒绝保存。
2. 扫描通过前禁止预览、下载和后续解析；必要时使用隔离区和异步状态。
3. 审计所有客户、客服、工程师、邮件和集成上传入口是否走同一安全链路。
4. 增加 EICAR、FOUND、OK、断连、超时、损坏/加密压缩包、超限文件和并发测试。
5. 记录租户、文件摘要、引擎/病毒库版本、结果和耗时，不记录附件原文。

## 选择建议

### 推荐 A：当前阶段

**ClamAV + FreshClam + 现有安全校验。** 成本最低、数据可留在内网，且当前 Go 代码已有协议接入，适合建立基本安全门禁。

### 推荐 B：加强 Office 和行业规则

在 A 上增加 **YARA-X + oletools**。将“包含宏”“发现可疑 DDE”与“确认感染”分级处理，避免把所有宏文档都误判为病毒。

### 推荐 C：高合规或高风险客户

采购并评估 **OPSWAT MetaDefender 等商业私有化/专有网络方案**。重点核对生产商用权、多租户、文件是否用于训练或共享情报、数据驻留、最大文件大小、并发、SLA、审计报告和退出后的数据删除。

## 最终推荐

当前 Helpdesk 选择 **ClamAV 私有化部署**；以实际误报、漏报和并发数据决定是否增加 YARA-X/oletools；客户明确要求多引擎、厂商 SLA 或合规证明时，再升级商业平台。不要使用 VirusTotal 公共免费 API 做商业生产扫描。
